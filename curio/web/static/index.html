Where Curio is headed

What you see today is the retrieval layer, a side-by-side look at how different search strategies feed an LLM. The bigger goal is for Curio to become an adaptive tutor. Here's what's coming next:

  1. Next

    Agentic retrieval

    Instead of one fixed search, the model decides what to look up, issuing multiple searches and reading full articles to answer multi-hop questions on its own.

  2. Soon

    Tutor mode

    Pick a topic and Curio builds a custom syllabus, teaches it concept by concept, and quizzes you as you go.

  3. Planned

    Memory & adaptation

    Curio remembers what you've learned across sessions and revisits your weak spots with spaced repetition.

  4. Planned

    Evals & observability

    Automated answer-quality scoring and full request tracing, so improvements are measured, not guessed.

You're looking at the same question answered three ways. Each column retrieves chunks with a different strategy, then a frozen LLM (Gemini 2.5 Flash) generates an answer using only those chunks. Same model, same corpus, different retrieval, different answers.
